# GLES 3.1 & 3.2 Changelog

Items with their boxes checked are completed.

## New features in OpenGL ES 3.1 include:

* [x] [Compute shaders](https://www.khronos.org/opengl/wiki/Compute_Shader): GPU-accelerated computing
* [x] [Indirect draw commands](https://www.khronos.org/opengl/wiki/Vertex_Rendering#Indirect_rendering) (with draw parameters in buffer storage)
* [x] Support for [framebuffers with no attachments](https://www.khronos.org/opengl/wiki/Framebuffer_Object#Empty_framebuffers)
* [x] Program interface queries
* [x] [Atomic counters](https://www.khronos.org/opengl/wiki/Atomic_Counter): GLSL variable type
* [x] Arrays of arrays (shading language only)
* [x] Shader bitfield operations (shading language only)
* [x] Shader helper invocation (shading language only)
* [x] Shader layout binding (shading language only)
* [x] [Explicit uniform location](https://www.khronos.org/opengl/wiki/Uniform_(GLSL)/Explicit_Uniform_Location): GLSL grammar
* [x] [Shader image load/store operations](https://www.khronos.org/opengl/wiki/Image_Load_Store): GLSL grammar
* [x] Texture gather operations: GLSL grammar
* [x] [Shader storage buffer objects](https://www.khronos.org/opengl/wiki/Shader_Storage_Buffer_Object): GLSL object
* [x] Separate shader objects
* [x] [Stencil texturing](https://www.khronos.org/opengl/wiki/Texture#Stencil_texturing)
* [x] Multisample formats for immutable textures
* [x] Vertex attribute binding

## New features in OpenGL ES 3.2 include:

Almost all features of the [Android extension pack](ANDROID_extension_pack_es31a.txt), incorporating by reference all of the following features - with the exception of the sRGB decode features of [`GL_EXT_texture_sRGB_decode`](EXT_texture_sRGB_decode.txt)

* [x] [`GL_KHR_blend_equation_advanced`](KHR_blend_equation_advanced.txt): Advanced blend equations.
* [x] [`GL_EXT_copy_image`](EXT_copy_image.txt): Copying subregions between image objects
* [x] [`GL_EXT_draw_buffers_indexed`](EXT_draw_buffers_indexed.txt) -> [`GL_EXT_draw_buffers2`](EXT_draw_buffers2.txt) + [`GL_ARB_draw_buffers_blend`](ARB_draw_buffers_blend.txt): Supporting blending on a per-draw-buffer basis
* [x] [`GL_KHR_debug`](KHR_debug.txt): Debug messages
* [x] [`GL_EXT_geometry_shader`](EXT_geometry_shader.txt) -> [`GL_ARB_geometry_shader4`](ARB_geometry_shader4.txt): Geometry shaders
* [x] [`GL_EXT_gpu_shader5`](EXT_gpu_shader5.txt) -> [`GL_ARB_gpu_shader5`](ARB_gpu_shader5.txt): Miscellaneous new shader functionality
* [x] [`GL_KHR_texture_compression_astc_ldr`](KHR_texture_compression_astc_hdr.txt): ASTC texture compression (LDR profile only)
* [x] [`GL_EXT_primitive_bounding_box`](EXT_primitive_bounding_box.txt): Primitive bounding boxes
* [x] [`GL_OES_shader_image_atomic`](OES_shader_image_atomic.txt) -> [`GL_ARB_shader_image_load_store`](ARB_shader_image_load_store.txt): Shader image atomic operations
* [x] [`GL_EXT_shader_io_blocks`](EXT_shader_io_blocks.txt): Shader interface blocks. GLSL grammar.
* [x] [`GL_OES_shader_multisample_interpolation`](OES_shader_multisample_interpolation.txt) -> [`GL_ARB_gpu_shader5`](ARB_gpu_shader5.txt): Shader multisample interpolation control
* [x] [`GL_OES_sample_variables`](OES_sample_variables.txt) -> [`GL_ARB_sample_shading`](ARB_sample_shading.txt): Sample variables
* [x] [`GL_OES_sample_shading`](OES_sample_shading.txt) -> [`GL_ARB_sample_shading`](ARB_sample_shading.txt): Sample shading control
* [x] [`GL_EXT_texture_buffer`](EXT_texture_buffer.txt): Texture buffer objects
* [x] [`GL_EXT_texture_border_clamp`](EXT_texture_border_clamp.txt) -> [`GL_ARB_texture_border_clamp`](ARB_texture_border_clamp.txt): New texture border color clamping algorithm
* [x] [`GL_EXT_texture_cube_map_array`](EXT_texture_cube_map_array.txt) -> [`GL_ARB_texture_cube_map_array`](ARB_texture_cube_map_array.txt): Texture cube map arrays
* [x] [`GL_EXT_tessellation_shader`](EXT_tessellation_shader.txt) -> [`GL_ARB_tessellation_shader`](ARB_tessellation_shader.txt): Tessellation shaders
* [x] [`GL_OES_texture_stencil8`](OES_texture_stencil8.txt) -> [`GL_ARB_texture_stencil8`](ARB_texture_stencil8.txt): STENCIL8 texture formats
* [x] [`GL_OES_texture_storage_multisample_2d_array`](OES_texture_storage_multisample_2d_array.txt): Texture multisample 2D arrays

and also include the following features, which are not part of the Android extension pack.

* [x] [`Draw calls specifying a base vertex parameter`](https://www.khronos.org/opengl/wiki/Vertex_Rendering#Base_Index): `glDrawElementsBaseVertex`
* [x] Floating-point framebuffers: `GL_RGBA16F` formats, etc., for HDR processing
* [x] Enabling robust buffer access as described in [`GL_KHR_robustness`](KHR_robustness.txt) (preventing crashes), but without the additional behavior defined by [`GL_KHR_robust_buffer_access_behavior`](KHR_robust_buffer_access_behavior.txt)
* [x] Support for querying `CONTEXT_FLAGS`, as needed by debug and robust buffer access functionality.
* [x] Support for querying `MULTISAMPLE_LINE_WIDTH_RANGE` and `MULTISAMPLE_LINE_WIDTH_GRANULARITY` (see section 13.6.4). Note that these are different query and enum values than desktop GL’s `SMOOTH_LINE_WIDTH_*`, which remain unsupported (Bug 13828). Can convert to `GL_SMOOTH_LINE_WIDTH_RANGE` and `GL_SMOOTH_LINE_WIDTH_GRANULARITY` in OpenGL.
